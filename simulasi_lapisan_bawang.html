Materi Sistem Operasi & 5 Fungsi Utamanya

Pelajari hakikat sistem operasi sebagai pengendali utama sumber daya komputer, arsitektur lapisan konsentris, dan 5 peran kunci sistem operasi dalam mengelola seluruh aktivitas komputasi modern.

Buka Lembar Kerja (LKPD)
Konsep Dasar

Apa itu Sistem Operasi (Operating System)?

Sistem Operasi (OS) adalah perangkat lunak sistem paling mendasar yang bertindak sebagai jembatan perantara (*intermediary*) antara pengguna (*brainware*), perangkat lunak aplikasi, dan perangkat keras (*hardware*).

Analogi Dirigen Orkestra:

Tanpa dirigen, setiap pemusik (CPU, RAM, Audio, Disk) akan bermain sesuka hati dan saling berebut hingga menghasilkan kekacauan suara. OS bertindak sebagai dirigen utama yang mengatur tempo, giliran bermain, dan memastikan seluruh instrumen berpadu harmonis.

Tanpa Sistem Operasi Komputer mati kaku, CPU tak tahu giliran eksekusi, memori tabrakan.
Dengan Sistem Operasi Multitasking lancar, memori terproteksi, hardware siap pakai.
Perbedaan Fundamental

Sistem Operasi vs Perangkat Lunak Aplikasi

Perangkat Lunak Sistem (Sistem Operasi):

Berjalan di lapisan dasar sejak komputer dinyalakan (*booting*), mengontrol sumber daya fisik secara langsung, dan menjadi wadah tempat aplikasi lain dapat berjalan.
Contoh: Microsoft Windows, Linux, macOS, Android.

Perangkat Lunak Aplikasi (User Space):

Dibuat untuk menyelesaikan kebutuhan spesifik pengguna (menghitung angka, mengetik dokumen, mengedit foto), dan dilarang mengakses hardware fisik secara langsung tanpa meminta izin ke sistem operasi.
Contoh: Kalkulator, Microsoft Word, Notepad, Photoshop.

Fungsi Inti OS

5 Fungsi Utama Sistem Operasi

Uraian komprehensif mengenai mekanisme kerja, peran teknis, dan contoh nyata dari setiap fungsi pengendali sistem operasi.

5 Pilar Pengendali Komputer
1 Process Management

Pengelolaan Proses

Suatu program yang sedang berjalan disebut Proses. Karena CPU mengeksekusi instruksi dengan sangat cepat, sistem operasi bertugas membagi waktu pemrosesan CPU.

Mekanisme Kerja Inti:

• CPU Scheduling & Time-Slicing: Membagi waktu prosesor menjadi fraksi milidetik agar banyak program (misal musik + kalkulator) bisa berjalan bersamaan (*multitasking*).

• Kill / Terminate Process: Menutup paksa aplikasi yang mengalami crash atau macet (*hang*) melalui Task Manager tanpa mematikan komputer.

Ringkasan Inti Fungsi (No. 1):
"Mengatur penjadwalan giliran eksekusi proses di CPU secara adil (time-slicing) agar komputer dapat menjalankan multitasking banyak aplikasi secara bersamaan, serta mematikan proses yang macet."
2 Memory Management

Pengelolaan Memori

Memori RAM adalah tempat data dan kode program berada saat dieksekusi CPU. OS mencatat alamat memori mana yang sedang dipakai dan mana yang masih bebas.

Mekanisme Kerja Inti:

• Alokasi & Dealokasi: Memberikan blok alamat RAM saat aplikasi dibuka, dan membebaskannya kembali saat aplikasi ditutup.

• Memory Protection: Mengisolasi ruang memori tiap program agar error pada satu software tidak merusak data software lain.

• Virtual Memory: Meminjam media penyimpanan (SSD/HDD) sebagai memori cadangan (*pagefile/swap*) jika RAM fisik penuh.

Ringkasan Inti Fungsi (No. 2):
"Mengalokasikan dan membebaskan blok alamat memori RAM untuk setiap aplikasi yang aktif, menjaga isolasi agar data aplikasi tidak saling bertabrakan, serta menyediakan memori virtual saat RAM fisik penuh."
3 Device & I/O Management

Pengelolaan Perangkat Keras & I/O

Perangkat input (keyboard, mouse, kamera) dan output (monitor, printer, speaker) memiliki karakteristik teknis berbeda. OS bertindak sebagai jembatan pengendali seragam.

Mekanisme Kerja Inti:

• Device Driver: Modul penerjemah perintah agar aplikasi tidak perlu tahu instruksi elektrik setiap merek hardware.

• Buffering & Spooling: Menampung antrean cetak dokumen printer atau pengetikan keyboard di memori penyangga.

• Hardware Interrupts: Menanggapi sinyal cepat perangkat saat tombol ditekan atau sensor menerima input.

Ringkasan Inti Fungsi (No. 3):
"Menjadi perantara pengendali perangkat keras (input/output) menggunakan device driver, mengatur antrean transfer data, sehingga aplikasi tidak perlu memprogram instruksi teknis rumit setiap perangkat keras."
4 User Interface Management

Pengelolaan Interaksi Pengguna (UI / Shell)

Komputer hanya memahami sinyal biner 0 dan 1. Sistem operasi menyediakan lapisan terluar ramah manusia berupa antarmuka grafis atau antarmuka teks baris perintah.

Mekanisme Kerja Inti:

• GUI (Graphical User Interface): Menampilkan jendela visual, tombol, ikon, dan desktop klik (Windows Explorer, GNOME).

• CLI (Command Line Interface): Menerima ketikan perintah baris teks (PowerShell, CMD, Bash) untuk otomatisasi skrip.

• System Call Dispatcher: Mengubah interaksi klik atau ketikan pengguna menjadi panggilan sistem (*System Call*) ke Kernel.

Ringkasan Inti Fungsi (No. 4):
"Menyediakan antarmuka interaksi visual (GUI) maupun baris perintah (CLI) yang memudahkan manusia memberi instruksi dan mengontrol sistem komputer tanpa harus mengetik kode biner mesin."
5 Utilities & System Maintenance

Penyediaan Utilitas (Utilities Management)

Sistem operasi melengkapi dirinya dengan berbagai program perkakas pembantu (*utility software*) yang bertujuan merawat kesehatan, mengamankan, dan mengoptimalkan performa komputer dalam jangka panjang.

Keamanan (Antivirus) Memindai dan melindungi berkas sistem dari serangan malware jahat (contoh: Windows Defender).
Perawatan Disk Merapikan susunan berkas terfragmentasi (*Disk Defragmenter*) dan membersihkan berkas sampah (*Disk Cleanup*).
Diagnostik Kinerja Memantau beban CPU, RAM, serta menghentikan aplikasi macet (*Task Manager*).
Ringkasan Inti Fungsi (No. 5):
"Menyediakan program perkakas pembantu (utility tools) yang berfungsi merawat kesehatan sistem, melindungi dari ancaman virus (antivirus), merapikan media penyimpanan (defrag), dan mendiagnosis kinerja komputer (Task Manager)."

Arsitektur Berlapis Sistem Komputer Model 4 Lapisan Standar (Hardware • Kernel • Shell • Utiliti)

Model Lapisan Bawang (The Onion Ring Architecture)

Seperti lapisan bawang konsentris, arsitektur sistem operasi dirancang berlapis-lapis untuk memisahkan hak akses dan melindungi kestabilan komputer. Model ini disederhanakan menjadi 4 lapisan hierarkis utama: Hardware di inti terdalam, dilindungi oleh Kernel, dijembatani oleh Shell, dan dilengkapi oleh Utiliti di lapisan terluar.

Klasifikasi Berdasarkan Fungsi

Pembagian peran perangkat lunak dalam ekosistem

1. Sistem Operasi (Operating System) Fondasi

Mengelola seluruh perangkat keras dan menjadi wadah bagi berjalannya aplikasi.

Contoh: Windows 11, Linux (Ubuntu), macOS Sonoma, Android, iOS.
2. Software Utilitas (Utility Program) Pemeliharaan

Membantu merawat, menganalisis, mengoptimalkan, dan mengamankan komputer.

Contoh: Antivirus (Windows Defender, Avast), WinRAR, Disk Cleanup, Task Manager.
3. Software Aplikasi (Application Software) Produktivitas

Membantu manusia menyelesaikan pekerjaan spesifik, komunikasi, atau rekreasi.

Contoh: Chrome, MS Word, Excel, Photoshop, VLC Media Player, Canva.
4. Perangkat Lunak Pemrograman Pembangun

Alat untuk menulis, mengompilasi, dan menguji kode program komputer.

Contoh: VS Code, Python Interpreter, GCC Compiler, Android Studio.

Klasifikasi Berdasarkan Lisensi

Hak cipta dan legalitas penggunaan perangkat lunak

1. Open Source (Sumber Terbuka) Bebas & Terbuka

Kode sumber dibuka untuk umum, boleh dimodifikasi, dipelajari, dan disebarluaskan.

Contoh: Linux Ubuntu, Blender 3D, VS Code, Python, GIMP, VLC.
2. Proprietary / Komersial Berbayar Tertutup

Kode sumber tertutup (rahasia pabrik) dan pengguna wajib membeli lisensi resmi.

Contoh: Microsoft Windows, Adobe Creative Cloud, AutoCAD, CorelDRAW.
3. Freeware Gratis Tertutup

Bebas diunduh dan digunakan tanpa bayar, namun kode sumber tetap dirahasiakan.

Contoh: Google Chrome, WhatsApp Desktop, Adobe Acrobat Reader.
4. Shareware / Trial Uji Coba Terbatas

Diberikan secara gratis untuk masa percobaan (misal 30 hari), setelah itu harus membeli.

Contoh: WinRAR (evaluasi 40 hari), Antivirus Trial Edition.
