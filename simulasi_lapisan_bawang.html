Klasifikasi Berdasarkan Fungsi

Pembagian peran perangkat lunak dalam ekosistem

1. Sistem Operasi (Operating System) Fondasi

Mengelola seluruh perangkat keras dan menjadi wadah bagi berjalannya aplikasi.

Contoh: Windows 11, Linux (Ubuntu), macOS Sonoma, Android, iOS.
2. Software Utilitas (Utility Program) Pemeliharaan

Membantu merawat, menganalisis, mengoptimalkan, dan mengamankan komputer.

Contoh: Antivirus (Windows Defender, Avast), WinRAR, Disk Cleanup, Task Manager.
3. Software Aplikasi (Application Software) Produktivitas

Membantu manusia menyelesaikan pekerjaan spesifik, komunikasi, atau rekreasi.

Contoh: Chrome, MS Word, Excel, Photoshop, VLC Media Player, Canva.
4. Perangkat Lunak Pemrograman Pembangun

Alat untuk menulis, mengompilasi, dan menguji kode program komputer.

Contoh: VS Code, Python Interpreter, GCC Compiler, Android Studio.

Klasifikasi Berdasarkan Lisensi

Hak cipta dan legalitas penggunaan perangkat lunak

1. Open Source (Sumber Terbuka) Bebas & Terbuka

Kode sumber dibuka untuk umum, boleh dimodifikasi, dipelajari, dan disebarluaskan.

Contoh: Linux Ubuntu, Blender 3D, VS Code, Python, GIMP, VLC.
2. Proprietary / Komersial Berbayar Tertutup

Kode sumber tertutup (rahasia pabrik) dan pengguna wajib membeli lisensi resmi.

Contoh: Microsoft Windows, Adobe Creative Cloud, AutoCAD, CorelDRAW.
3. Freeware Gratis Tertutup

Bebas diunduh dan digunakan tanpa bayar, namun kode sumber tetap dirahasiakan.

Contoh: Google Chrome, WhatsApp Desktop, Adobe Acrobat Reader.
4. Shareware / Trial Uji Coba Terbatas

Diberikan secara gratis untuk masa percobaan (misal 30 hari), setelah itu harus membeli.

Contoh: WinRAR (evaluasi 40 hari), Antivirus Trial Edition.
