1 Aktivitas 1: Mengenal Pseudocode

Pseudocode (Kode Semu) adalah cara penulisan algoritma yang menyerupai bahasa pemrograman, namun menggunakan bahasa manusia agar lebih mudah dipahami secara logika.

Terdapat 3 proses utama: INPUT (Data awal), PROSES (Rumus/langkah), dan OUTPUT (Hasil akhir).

Kata Kunci Contoh Pemakaian Fungsi / Kegunaan (Ketik di sini)
INPUT / READ INPUT nama_siswa
OUTPUT / PRINT PRINT "Total Harga: ", total
<- (Tanda Panah) luas <- panjang * lebar
IF ... THEN IF nilai > 75 THEN PRINT "Lulus"
ELSE ELSE PRINT "Gagal"
do while do PRINT angka while angka < 5
