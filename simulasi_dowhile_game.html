mengeksekusi DO-WHILE loop

# Program Tebak Angka (1-10)
Program Tebak_Angka
Deklarasi:
  rahasia, tebakan : integer
Algoritma:
  rahasia <- RANDOM(1, 10)
  DO
    READ tebakan
    IF tebakan < rahasia THEN
      PRINT "Terlalu Kecil!"
    ELSE IF tebakan > rahasia THEN
      PRINT "Terlalu Besar!"
    END IF
  WHILE tebakan != rahasia
  PRINT "Selamat! Tebakan Benar!"
Ciri Khas DO-WHILE: Blok kode di dalam DO akan selalu dikerjakan minimal 1 kali sebelum syarat di WHILE diperiksa. Cocok untuk input game!
